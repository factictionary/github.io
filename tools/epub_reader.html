How In-Browser EPUB Parsing Works (OCF + OPF Architecture)

The IDPF / W3C EPUB 2 and EPUB 3 specification packages digital books inside an Open Container Format (OCF) ZIP archive. When you select an `.epub` file above, our client-side parser executes four steps entirely in your browser RAM:

  1. Container Discovery (`META-INF/container.xml`): Reads the root XML pointer to locate the book's primary Open Packaging Format (`.opf`) manifest file.
  2. Metadata & Manifest Indexing: Extracts Dublin Core metadata (`dc:title`, `dc:creator`, `dc:language`) and maps every manifest item ID to its internal XHTML chapter path and embedded image `Blob` URLs.
  3. Spine Sequencing: Builds the linear reading order defined in the `` node so you can step seamlessly from cover to copyright to chapters.
  4. Sandboxed DOM Sanitization: Strips any external script tags while preserving headings, paragraphs, blockquotes, tables, and embedded illustrations.
