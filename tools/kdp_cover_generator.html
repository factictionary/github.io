How Spine Width & Layout Are Calculated

Amazon KDP prints paperback books by wrapping a single continuous printed sheet around the interior pages. The required total wrap width equals Back Cover Width + Spine Width + Front Cover Width + 0.25" Bleed (0.125" on left and right outer edges).

Single-Line Spine Text Placement

Per standard publishing guidelines, spine title and author text run vertically down the spine on a single continuous line. For books under 24 pages, KDP recommends leaving the spine blank. For 24+ page books, this tool dynamically scales the font size to fit within the spine's safe print area with a safety buffer.

All rendering occurs in your web browser using HTML5 Canvas and pdf-lib. Your images are never transmitted to any external server, ensuring complete confidentiality for unreleased manuscript covers.
