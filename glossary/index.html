Technical & Digital Publishing Glossary

Clear, authoritative definitions covering Client-Side WebAssembly privacy, Android & Google Play engineering, Amazon KDP print production, and creator workflows.

12 Testers for 14 Days Rule (Google Play Closed Testing)

Android & Google Play

A mandatory verification policy enforced by Google Play for personal developer accounts created after November 2023. Before applying for Production Access, developers must run a closed testing track with at least 12 opted-in testers continuously for 14 consecutive days. If tester count drops below 12 on any day, the 14-day clock resets.

Android App Bundle (AAB)

Android & Google Play

The official publishing format required by Google Play Store since August 2021. Unlike monolithic APKs, an `.aab` file contains all compiled code and resources of an app but defers APK generation and signing to Google Play, which serves optimized split APKs tailored to each user's device ABI and screen density.

Applicant Tracking System (ATS) Parsing

WebAssembly & Privacy

Automated recruitment software (such as Workday, Greenhouse, and Lever) used by employers to extract text from PDF and DOCX resumes. Multi-column layouts, floating text boxes, and rasterized graphics often corrupt the ATS reading order, causing qualified candidates to score poorly on keyword matching.

App Store Optimization (ASO)

Android & Google Play

The process of improving mobile app visibility and conversion rates inside app stores like Google Play. Key ASO ranking factors include title keywords (30 characters on Google Play), short description (80 characters), long description keyword density, crash-free ANR rates, and Day-1/Day-7 user retention.

Backend Keywords (Amazon KDP 7-Slot System)

KDP & Publishing

Seven metadata fields in the Amazon Kindle Direct Publishing dashboard (each allowing up to 50 characters) where authors enter search phrases shoppers use to find books. Properly packing non-repetitive long-tail phrases into all seven slots significantly increases organic Amazon search impressions.

Base64 Encoding

WebAssembly & Privacy

A binary-to-text encoding scheme that represents binary data in an ASCII string format using 64 printable characters. Widely used for embedding small images (Data URLs) directly inside HTML/CSS files and transmitting binary payloads safely over text-based protocols like JSON and MIME email.

Bleed vs. No-Bleed (Print-on-Demand)

KDP & Publishing

In print production, "Bleed" refers to extending background illustrations or colors 0.125 inches (3.2 mm) beyond the final trim line on the top, bottom, and outside edges so no white margin appears if the mechanical blade shifts during trimming. A 6" × 9" book with bleed requires a 6.125" × 9.25" interior PDF page size.

Blob URL (`URL.createObjectURL`)

WebAssembly & Privacy

A browser DOM API that creates a temporary `blob:` reference pointing directly to an in-memory `File` or `ArrayBuffer` inside the user's device RAM. Factictionary tools use Blob URLs so users can download merged PDFs, compressed images, and trimmed videos instantaneously without downloading from an external server.

Client-Side Processing (Zero-Upload Architecture)

WebAssembly & Privacy

A software architecture where file parsing, compression, encryption, and rendering execute entirely on the end user's CPU and GPU inside the web browser sandbox. Because zero bytes are transmitted over the network (`POST` requests are never made), confidential tax, legal, and medical documents remain 100% private.

Cream vs. White Paper Stock Multiplier

KDP & Publishing

Different paper stocks have distinct caliper thicknesses that change a paperback book's spine width. On Amazon KDP, standard white paper measures 0.002252 inches per page, whereas cream paper is thicker at 0.0025 inches per page. Using the wrong multiplier causes cover wrap text to shift outside safe spine margins.

Cryptographic Hash (SHA-256 / SHA-512)

WebAssembly & Privacy

A deterministic one-way mathematical function that converts arbitrary input data into a fixed-length hexadecimal digest. Even a single character change alters the entire output hash (the avalanche effect), making SHA-256 essential for verifying file integrity, Android keystore certificates, and password verification.

Eye-Line Offset (Camera Teleprompting)

Creator & Audio/Video

The angular distance between a smartphone's front-facing camera lens and the scrolling script text on screen. Keeping the active reading line within 1.5 centimeters of the physical lens eliminates horizontal "windshield-wiper" eye movement and preserves natural eye contact on Instagram Reels and YouTube Shorts.

Integrated Loudness (LUFS)

Creator & Audio/Video

Loudness Units Full Scale — the international broadcast standard (ITU-R BS.1770) for measuring perceived audio volume across an entire video or podcast track. YouTube, Spotify, and Instagram Reels normalize audio to roughly `-14 LUFS`, meaning quieter recordings sound weak while overly loud tracks get dynamically crushed.

JSON Schema & Minification

WebAssembly & Privacy

JavaScript Object Notation (JSON) is the standard data interchange format for REST APIs and mobile app configurations. Formatting (pretty-printing) adds indentation for human debugging, while minification strips all non-essential whitespace and line breaks to reduce network payload size.

WebAssembly & Privacy

Computer vision technology that detects printed or handwritten characters inside scanned PDF pages or photographs and converts them into selectable, searchable machine text. Modern WebAssembly ports of Tesseract allow OCR to run directly inside a browser tab without uploading scanned IDs or invoices.

Tambola / Housie 3×9 Ticket Matrix

Android & Google Play

The mathematical grid structure used in Indian Tambola (90-ball British Bingo). Each ticket consists of 3 horizontal rows and 9 vertical columns (Column 1 holds numbers 1–9, Column 2 holds 10–19, ..., Column 9 holds 80–90). Exactly 5 numbers appear in each row for a total of 15 numbers per ticket.

WebAssembly (Wasm)

WebAssembly & Privacy

A portable, low-level binary instruction format that runs at near-native speed inside modern web browsers (Chrome, Firefox, Safari, Edge). WebAssembly enables C, C++, and Rust libraries (such as FFmpeg, PDF-lib, and image codecs) to execute inside a strict memory-safe browser sandbox without server backends.
